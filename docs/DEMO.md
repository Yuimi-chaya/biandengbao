# 合成演示

README 的截图和视频来自 `tools/demo.py`：真实前端、模拟原生 IPC、虚构项目与聊天。它不读取真实 Codex 目录、不启动模型、不连接桌面工具通道，也不证明实际模型操作已经验收。

在仓库根目录执行：

```sh
python -B tools/demo.py
```

打开 `http://127.0.0.1:8789`，点击连接。服务只绑定本机回环地址，最长运行 30 分钟。项目、模型 ID、工具输出和上下文用量均为合成值；模拟创建复用演示线程，不会创建真实聊天。

向 `.tmp/demo-control.json` 写入 `{"mode":"stream"}` 可展示逐步回复，写入 `{"mode":"idle"}` 恢复完成态。创建空文件 `.tmp/demo.stop` 可协作停止；下次运行请使用新的 `--stop-file`，或确认旧演示已退出后移除旧停止文件。

公开素材通过代码驱动独立的无头 Chrome，在上述合成服务中完成真实网页交互，不使用个人浏览器配置。录制前等待字体、数据和布局就绪；手机视口为 390 × 844、设备像素比为 2。连续采集 780 × 1688 像素画面，按实际时间编码为 25 fps H.264 视频，并加上“便蹬宝 · 合成场景”页脚，成片为 780 × 1740。视频没有配音，不拼接稀疏截图或人为拉长帧时长。

README 的手机截图保留 780 × 1688 无损 PNG，以 390 像素宽显示；工作区总览保留 2880 × 2400 无损 PNG。完整 MP4 放在 Release，README 提供入口，不使用小尺寸动图代替高清视频。

录制检查包括页面错误、横向溢出、实际采集尺寸，以及视频首帧与源画面的对照。它们只验证展示素材，不验证真实模型行为。界面支持项及真实验证边界以 README 和 VERIFICATION.md 为准。
